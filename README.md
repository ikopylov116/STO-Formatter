# СТО Formatter

Desktop-приложение для проверки и автоматизированного оформления документов DOCX по профилю **СТО P_305.2026**.

> Важно: версия 0.1 — рабочий первый релиз. Она автоматизирует базовое текстовое оформление, поля, нумерацию страниц, диагностику структуры и типовые нарушения. Она не заявляет полную автоматическую проверку всех требований стандарта (рисунки, таблицы, формулы, API, код, политика ИИ и т. п.).

## Что умеет

- открывать DOCX без изменения исходного файла;
- проверять поля, шрифт, интервалы, абзацный отступ и двойные пробелы;
- распознавать структурные элементы и нумерованные заголовки;
- создавать новый оформленный DOCX;
- добавлять поле автоматической нумерации страниц;
- включать обновление полей Word при открытии документа;
- показывать результаты проверки с идентификаторами правил;
- работать модульно: профиль СТО отделён от движка документа и UI.

## Запуск

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python run.py
```

## Архитектура

```text
app/
├── domain/       # модели профиля и результатов проверки
├── sto/          # правила конкретного СТО
├── document/     # чтение, анализ и форматирование DOCX
└── ui/           # графический интерфейс
```

## Безопасность исходника

Операция оформления всегда сохраняет результат в новый путь. Исходный DOCX не перезаписывается.

## Источник требований

Профиль разработан на основе предоставленного пользователем документа `P_305.2026.pdf`. Точные требования, которые ещё не автоматизированы, должны добавляться в виде отдельных правил с идентификаторами разделов стандарта.
