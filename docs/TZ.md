# ТЗ — СТО Formatter

## Цель

Создать модульное desktop-приложение для подготовки DOCX-документов по СТО P_305.2026.

## Первый рабочий релиз

1. Импорт DOCX.
2. Проверка базовых параметров оформления.
3. Автоматическое форматирование в новый DOCX без перезаписи исходника.
4. Сквозное поле нумерации страниц.
5. Диагностические сообщения с ID правил.
6. Автотесты и CI.

## Правила из текущего профиля

- основной текст: Times New Roman, 14 pt;
- межстрочный интервал: 1,5;
- выравнивание обычного текста: по ширине;
- отступ первой строки: 1,25 см;
- интервалы до/после: 0/0;
- поля: 30/10/20/20 мм;
- структурные элементы и заголовки распознаются отдельно.

## Следующий этап

Добавлять отдельными модулями содержание, правила рисунков и таблиц, формулы, список источников по ГОСТ Р 7.0.100–2018, приложения, код, API и требования раздела о применении ИИ. Перед автоматизацией каждого блока сверять его с P_305.2026.
